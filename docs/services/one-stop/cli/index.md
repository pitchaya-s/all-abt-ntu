# One Stop: CLI reference

[Service overview](../index.md) · [MCP reference](../mcp/index.md)

One Stop commands use your signed-in student account. Run `ntu onestop --help` to browse groups, or choose the task below. Data commands offer `--json` where shown; downloads and changes require local confirmation.

- [Catalog](catalog.md) — 4 commands
- [Requests](requests.md) — 6 commands
- [Appointments](appointments.md) — 2 commands
- [Knowledge](knowledge.md) — 13 commands
- [Attachments](attachments.md) — 5 commands
- [Payments, cart and favourites](commerce.md) — 18 commands
- [Dashboard and profile](account.md) — 10 commands

Requests, appointment bookings and checkout run as interactive single-command workflows. Temporary form state stays in that process, so you do not need to manage draft IDs between commands.
